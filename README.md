# 🎉 Website Ucapan Ulang Tahun Mba Kei (7 November 2026)

Website interaktif spesial untuk merayakan hari ulang tahun **Mba Kei** pada tanggal **7 November 2026**. Dibuat menggunakan **Vanilla HTML, CSS, dan JavaScript murni** dengan desain responsif, estetika modern, serta berbagai elemen interaktif.

---

## ✨ Fitur Interaktif

1. **Efek Confetti & Sparkle di Mana Saja**:
   - Klik di sembarang area layar untuk memunculkan semburan confetti, efek visual partikel, suara lembut, dan kartu kata melayang (*"HBD Mba Kei! ✨"*, *"Queen of Nov 7 👑"*, *"Bahagia Selalu 💖"*).
2. **Amplop Bersegel Lilin Emas 3D**:
   - Amplop dengan animasi segel emas bertuliskan `KEI` yang dapat diklik untuk membuka surat ucapan dan doa tulus.
3. **Kue Ulang Tahun & Lilin Doa Interaktif**:
   - Tiup kelima lilin satu per satu (setiap lilin menyimpan doa harapan berbeda), atau gunakan tombol **Tiup Semua Lilin** maupun fitur interaktif **Tiup Pakai Mikrofon**.
   - Setelah semua lilin padam, tombol **Potong Kue Spesial 🍰** akan aktif disertai pesta kembang api.
4. **Taman Balon Harapan 🎈**:
   - Balon melayang warna-warni yang dapat dipecahkan dengan efek suara *pop* untuk membuka kartu afirmasi dan pujian.
5. **6 Kotak Kado Misteri & Toples Bintang 🌟**:
   - Buka kado misteri dengan berbagai kejutan voucher dan doa.
   - Kocok toples bintang atau buka *fortune cookie* untuk menarik gulungan doa acak.
6. **Kotak Musik & Kalimba Ulang Tahun 🎹**:
   - Mainkan nada kalimba secara manual (Do–Do') menggunakan klik mouse atau keyboard `1`–`8`.
   - Tombol instan untuk memutar melodi *"Happy Birthday Mba Kei"* secara otomatis dengan Web Audio API synthesizer.
7. **Scrapbook Polaroid 3D & Dinding Harapan 📸**:
   - Kartu polaroid 3D dengan efek flip bolak-balik.
   - Form penambahan ucapan doa yang otomatis tersimpan di `localStorage` browser.
8. **Misi 7 Kejutan (`👑 Kejutan: 0/7`)**:
   - Melacak progres eksplorasi pengguna di pojok kanan atas hingga dinobatkan sebagai *Grand Queen of 7 November 2026*.

---

## 🚀 Cara Menjalankan Secara Lokal

Buka file `index.html` langsung di browser favorit Anda, atau jalankan melalui local web server:

```bash
# Menggunakan npx serve
npx serve .

# Atau menggunakan Python
python3 -m http.server 3000
```

Buka URL `http://localhost:3000` di peramban Anda.

## 🌐 Publikasi via GitHub Pages

Agar Mba Kei dapat langsung membuka website ini melalui link di HP atau laptop:
1. Buka repository [irsyaad06/k](https://github.com/irsyaad06/k).
2. Masuk ke tab **Settings** > **Pages**.
3. Pada bagian **Build and deployment** > **Branch**, pilih cabang `main` dan folder `/ (root)`, lalu klik **Save**.
4. Website akan aktif di: `https://irsyaad06.github.io/k/`
