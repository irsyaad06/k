# Panduan Folder Galeri Foto Mba Kei 📸🎓

Kamu bisa menaruh foto-foto Mba Kei (foto wisuda, foto ulang tahun, foto hangout, dsb) langsung ke dalam folder ini:
`assets/gallery/`

Contoh nama file yang didukung:
- `kei-1.jpg` atau `kei-1.png`
- `kei-2.jpg`
- `wisuda-kei.jpg`
- `ultah-kei.jpg`

Di website, sudah disiapkan:
1. Galeri visual default yang estetik lengkap dengan caption ucapan wisuda & ultah.
2. Fitur "Tambah Foto Mba Kei" langsung dari browser (bisa pilih foto langsung dari galeri HP / laptop tanpa perlu deploy ulang!).
3. Lightbox zoom untuk melihat foto dalam ukuran penuh saat diklik.
